# Deadline Daisy Campus Planner

Build a Campus Planner student deadline management web app with a working database. Include a dashboard, course list, and the ability to add, view, complete, and delete assignments. Use Supabase for persistent data storage with Users, Courses, and Tasks tables. Include realistic sample data and a clean responsive design. Do not use localStorage as the database.
